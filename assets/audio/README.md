# Música de fondo

Coloca aquí tu canción con este nombre exacto:

| Archivo | Dónde se usa |
|---|---|
| `song.mp3` | Empieza a sonar en cuanto tocas el sello de cera y se abre el sobre. Hay un botón flotante (nota musical) para pausarla/reanudarla en cualquier momento. |

## Recomendaciones
- Formato `.mp3` (el más compatible con todos los navegadores).
- Si no pones el archivo, el sitio funciona normal — simplemente no suena nada hasta que agregues `song.mp3`.
- Cuida los derechos de autor: usa una canción que tengas licencia para usar, o música libre de derechos.
- Comprime el audio (128–192 kbps es suficiente para música de fondo) para que no pese demasiado — idealmente menos de 5 MB.
- Si prefieres que la música no se repita en bucle, quita el atributo `loop` de la etiqueta `<audio id="bgMusic">` en `index.html`.
